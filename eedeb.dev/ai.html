How I work

Design the base, build it up

I'm not pretending the paint on this page is hand-mixed. The structure underneath is the part I care about.

01 / STRUCTURE
Design the system

Agent structure, data flow, model routing, where state lives. This is done by hand, on purpose — it's the part that decides whether the thing works or falls over.

02 / BUILD
Write the core

Python for the logic, PyTorch when a small model beats an API call, Flask and SQLite for the service. Deployed on Linux with NGINX in front.

03 / SURFACE
Let AI do the paint

Frontends get vibe-coded with Claude Code, then reviewed and shipped. Fast, polished, and honestly better than what I'd hand-write in CSS.
